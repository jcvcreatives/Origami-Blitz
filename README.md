# Paper Craft Crush

A tactile origami & layered construction paper diorama Match-3 game built for **Android (Kotlin + Jetpack Compose)** and **GitHub Pages Web (`docs/index.html`)**.

## How to Play on the GitHub Website (GitHub Pages)

1. Push this project to your GitHub account using the **GitHub / Export** button in the top bar of Google AI Studio.
2. Open your repository on **github.com**.
3. Click **Settings** (top tab) → **Pages** (left sidebar).
4. Under **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` (or `master`) and select the **`/docs`** folder, then click **Save**.
5. Wait ~30 seconds and open your live `https://<your-username>.github.io/<repo-name>/` URL to play **Paper Craft Crush** directly in any desktop or mobile browser!
